## B1 线性表（✅ 已归位 · 存档题库）

> 自查建议：顺序表挑 5 题（含 2011/2013/2018/2020 真题向）+ 链表挑 5 题（含 2009/2012/2015/2019 真题向），计时默写。

### 代码大题（顺序表 · C 手写）
- **高效逆置**：线性表采用顺序存储，设计高效算法将其中所有元素逆置，要求空间复杂度 O(1)。
- **删除所有值 = x 的元素**：对顺序表 L，删除其中所有值为 x 的元素，要求时间 O(n)、空间 O(1)（不新建表）。
- **有序表删除 (s, t) 区间**：从有序顺序表中删除其值在给定值 s 与 t 之间（s < t）的所有元素；s/t 不合理或表空时给出错误提示。
- **无序表删除 (s, t) 区间**：从（无序）顺序表中删除值在给定区间 [s, t] 内的所有元素（要求相对次序不变、高效）。
- **有序表去重**：从有序顺序表中删除所有值重复的元素，使表中元素值互不相同（一趟）。
- **合并两个有序表**：将两个有序顺序表合并为一个新的有序顺序表（不破坏原表）。
- **两段互换**：一维数组 A[m+n] 依次存放两个线性表 (a₁…aₘ)、(b₁…bₙ)，编写算法将两表位置互换，使 (b₁…bₙ) 在前（三段逆置法；★2010 真题为"循环左移 p 位"，同一技巧，两种问法都练）。
- **查找 x 并前移/插入**：递增有序顺序表，用最少时间查找值为 x 的元素：找到则与后继元素交换；找不到则插入并保持有序。
- **删除最小值**：从顺序表中删除值最小的元素（假设唯一），由函数返回被删值，空出的位置由最后一个元素填补。
- **双升序序列中位数** ★2011：长度为 L 的升序序列 S，第 ⌈L/2⌉ 个位置元素为中位数。两个等长升序序列 A、B 长度均为 n，设计时间空间尽可能高效的算法，求两序列全部 2n 个元素的中位数。
- **主元素** ★2013：数组 A[0..n-1] 中，若某元素出现次数多于 n/2 则称其为主元素。设计尽可能高效的算法找出主元素；不存在返回 -1。
- **未出现的最小正整数** ★2018：给定含 n（n ≥ 1）个整数的数组，设计时间空间尽可能高效算法找出数组中未出现的最小正整数（如 {-5,3,2,3} 输出 1；{1,2,3} 输出 4）。
- **三元组最小距离** ★2020：三元组 (a,b,c) 的距离 D = |a−b| + |b−c| + |c−a|。给定三个升序数组，求所有可能三元组中最小距离（三指针贪心）。

### 代码大题（单链表 · C 手写）
- **删除所有值 = x 的结点**：带头结点单链表，删除所有值为 x 的结点（先写循环版，再写递归版）。
- **删除最小值结点**：带头结点单链表，删除值最小的结点（唯一），并释放空间。
- **就地逆置**：带头结点单链表就地逆置，空间 O(1)（头插法重建；链表逆序高频考法）。
- **删除值在 (mink, maxk) 之间的结点**：带头结点单链表，删除值介于两给定值之间的所有结点。
- **有序链表去重**：按值递增的单链表，删除重复值结点（一趟双指针）。
- **两递增表归并**：两个按值递增的单链表，就地归并为一个仍递增的单链表，只能复用原有结点。
- **奇偶拆表**：带头结点单链表 A，拆成两个表：A 保留序号为奇数的结点，新表 B 含序号为偶数的结点（相对次序不变）。
- **无序表去重**：无序单链表删除值重复的结点（基础 O(n²) 版 + 布尔数组空间换时间版，比较时空差异）。
- **绝对值去重** ★2015：带头结点单链表中结点 data 的绝对值 ≤ n（n 给定正整数），删除链表中绝对值相等的结点，仅保留第一次出现的。
- **子序列判断**：两个带头结点单链表 A、B，判断 B 是否为 A 的连续子序列。
- **循环双链表对称**：带头结点的循环双链表，判断其结点值是否关于中心对称（左右指针相向扫描）。
- **两循环链表相接**：两个带头结点循环单链表 h1、h2，编写函数把 h2 链接到 h1 之后，仍构成一个循环单链表。
- **倒数第 k 个结点** ★2009：带头结点单链表只给出头指针，设计尽可能高效算法查找倒数第 k（k ≥ 1）个结点：一趟完成，成功输出值，失败返回相应标志。
- **链表判环**：单链表（结构如上），判断是否存在环；若存在，找出环的入口结点（快慢指针，推导相遇点到入口的距离关系）。
- **公共后缀起点** ★2012：两单词可共享相同后缀存储，两个带头结点单链表分别存储两个单词（可能共享结点），找出两链表共同后缀的起始位置。
- **重排链表** ★2019：带头结点单链表保存 L = (a₁,a₂,…,aₙ)，重排为 L′ = (a₁,aₙ,a₂,aₙ₋₁,a₃,…)，要求空间 O(1)、时间尽可能高效（找中点 + 逆置后半 + 交替插入）。

### 概念·推演
- **存储结构对比**：顺序表 vs 链表：按位/按值查找、头尾插入删除的复杂度对比，并论述"何时选顺序表、何时选链表"（含缓存局部性视角）。
- **静态/循环链表**：静态链表、循环链表、双链表各自的适用场景辨析。
- **移动次数推导**：在长度为 n 的顺序表中随机位置插入/删除元素，平均移动次数的推导过程（写出求和与结果）。

### 代码大题
- **ADT 手写**：顺序栈（判空判满）、链栈、循环队列（判空判满，说明采用的判满方案）的完整 C 实现（每种 ≥5 个基本操作）。
- **共享栈**：两个栈共享数组空间 Stack[maxsize]，实现入栈/出栈/判满/判空（判满 = 两栈顶指针相邻）。
- **括号匹配**：判别表达式中的括号（( ) [ ] { }）是否匹配，用栈实现完整算法。
- **数制转换**：利用栈将十进制数 N 转换为 d 进制（2 ≤ d ≤ 16）并输出。
- **表达式求值**：中缀表达式转后缀表达式 + 后缀求值（支持 + − * / 与括号）；或直接实现中缀求值，说明用到的两个栈。

### 概念·推演
- **出栈序列合法性**：若 1,2,…,n 依次入栈，判断一个给定序列是否为合法出栈序列（给出判断规则，再对 3-4 个具体序列推演验证）。
- **循环队列判满三方案**：牺牲一个存储单元 / 增设计数器 / 增设标志位，三种判满判空方案对比，写出各方案的队满条件。
- **递归与非递归**：用栈消除递归的适用条件论述——哪些递归可机械转换（尾递归/单分支），哪些不适合（举例）。
- **栈深度与空间**：递归调用栈深度与问题规模的关系（n 层递归空间 O(n)），结合"递归爆栈"说明栈空间限制。
