# 刷题选题指南

> 原则：刷题服务两个目标——**408 数据结构（洛谷对齐）**与**实习面试（LeetCode 对齐）**。
> "一做就不会、一搞就大半天"不是意志力问题，是**选题问题**：难题不该在"做题模式"里硬扛，要换"学习模式"。

## 一、选题三原则

1. **知识点对齐**：只做当前手写清单知识点的题（见 [[手写训练/目录|手写训练目录]]），不随机刷。清单到哪项，题就做哪组。
2. **难度带管理**：绿区独立做，黄区学题解，红区不碰（见 §三）。
3. **时间盒**：单题独立思考 ≤ 30min，到点看题解、换模式，不恋战。**恋战是计划杀手。**

## 二、两种模式（解决"一做就不会"）

- **模式A 独立做**：绿区题。20-30min 无进展 → 看题解，转入模式B。看题解不是失败，是标准流程。
- **模式B 学题解**：黄区题。看懂 + 复述思路 + **次日关题解复写**。若题解也要 >1h 才看懂 → 说明这道题是红区，知识点没到位，先回去手写，别硬啃。
- **三遍法迁移到题**：当天跟抄题解 → 次日关题解复写 → 隔周独立重写（能写出来才算消化）。写完按规范记入 `编程工具箱/算法题/`（没独立做出来就只写官方题解，规范允许）。

## 三、难度带定义（按你蓝桥杯 Java B 国三的基准）

| 带 | 洛谷 | LeetCode | 处理 |
|---|---|---|---|
| 绿 | 入门 ~ 普及+ | 简单 ~ 中等 | 模式A 独立做 |
| 黄 | 提高- ~ 提高 | 高频困难 | 模式B 学题解，每周 ≤ 2 |
| 红 | 提高+ | 冷门困难 | 不碰 |

- **校准信号**：独立完成率 60-80% 最优；< 50% 降一个难度带（别硬扛）；> 90% 升一个难度带。

## 五、两阶段切换（对齐两条线）

- **大二上（手写训练季）**：洛谷为主（408 对齐），按 §四 树图题单推进，王道课后大题优先；LeetCode 只做对应树图题。**学期目标 ~60 题。**
- **大二下（面试季前，2027.03 起）**：切 LeetCode —— 剑指 Offer 高频 30 题 + Hot 100 核心分组（数组/字符串/哈希/双指针/二分/栈队列/树）~40 题，图与 DP 选做。**2027.06 前累计 ~120-150 题。**

> 别忘了主力：**王道课后大题 > 洛谷题 > LeetCode**。408 考的是手写，王道大题（用 C 手写）优先级最高，洛谷/LeetCode 是手感和面试的补充。

## 六、周节奏（刷题 40min + 英语 20min/天）

- 周一/二/四/五：每天 40min 刷题（绿区独立做，每周挑 2 晚加模式 B 黄区题）+ 20min 英语单词（与路线图 §八 对齐；周三机动日不排任务）
- 题解消化流程：当天看懂 → 次日复写 → 隔周独立重写，记入 `编程工具箱/算法题/`
- 周日周测：手写默写 1 项（含排序快过项，与刷题互不影响）
