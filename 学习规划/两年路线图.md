## 一、四条顶层原则

1. **实习窗口不可逆**：大二暑假是本科唯一与考研零冲突的实习窗口（大三暑假是 408 冲刺黄金期，绝不让位）。大二全年一切服务于 2027 暑假实习。
2. **408 战线最长**：408 四科里只有数据结构需要"大二就开始积累"。大二的目标不是会做题，而是**脱稿手写**——不查资料写出树/图算法，并讲清复杂度。
3. **一份时间两份收益**：后端技能栈与 408 考点高度重叠（见 §五 反哺表）。每学一个后端知识点，顺手标注对应 408 考点。
4. **保研线已放弃**：保研名额 600 人仅十几个（~2.5%），放弃是理性决策。绩点保持前 30% 安全线即可（复试材料 + 奖学金不拖后腿），省下的时间全部投入技能与考研。

## 四、树与图脱稿手写协议（核心薄弱点专项）

### 三遍法
第 1 遍：看懂 + 跟抄（允许抄书）→ 第 2 遍：关书手写（允许查 API）→ 第 3 遍：隔一周脱稿默写 + 口头讲复杂度。每项过完第 3 遍才算通过。

### 树（8 项）
1. 二叉树链式存储：前/中/后序 递归+非递归（栈）、层序（队列）
2. 二叉搜索树 BST：插入 / 删除（三情况）/ 查找 / 中序有序性
3. AVL：四种旋转（LL/RR/LR/RL）+ 平衡因子维护
4. 堆：数组实现、上浮/下沉、建堆 O(n)、堆排序
5. 并查集：路径压缩 + 按秩合并，连通分量应用
6. 哈夫曼树：建树 + 编码（408 大题常客）
7. B 树：结构 + 插入删除规则（408 概念题为主，不要求完整手写）
8. 红黑树：性质 + 插入变色旋转理解（面试高频，联系项目里 HashMap 树化）

### 图（7 项）
1. 邻接矩阵 / 邻接表，手写互转
2. BFS / DFS：递归+非递归、连通分量、环检测
3. 拓扑排序（Kahn + DFS 两版）+ 关键路径 AOE（408 重点）
4. Dijkstra：朴素 O(V²)，过程推演
5. Floyd：三重循环 + 路径记录
6. Prim / Kruskal：手写 + 并查集配合
7. 最短路 / 最小生成树 复杂度与适用场景辨析（面试爱问"为什么"）

### 验收标准
- 每项 20-30 分钟内**无错脱稿**写完整段代码
- 写完后 30 秒内说出时间/空间复杂度
- 每周日周测：计时默写 1 项（随机抽）

### 语言分工（C / Java / C++ 各司其职）
- **408 手写 = C**：王道体系，考场按逻辑给分
- **刷题 / 实习 = Java**：蓝桥杯 Java 组、后端岗
- **C++ 不设独立学习轨道**：本路线中无明确收益点（408 用 C 足够，复试机试绝大多数院校允许 Java，竞赛已走 Java 组）
- 但需 **C++ 阅读能力**：网课代码标 "C/C++" 实际多为 C 语法 + 少量便利（引用 & / new / bool / 常用 STL），洛谷题解同理；会读即解锁全部教材与题解（见 [[C++阅读速览]]，对照 Java 速记，2-3 天弹性时间）
- **C++ 兴趣线（内存/性能）**：真有兴趣则归入大三寒假或考研后，不进当前预算；指针/引用/内存布局对 408 组成原理与理解 JVM 有反哺，兴趣不白费
- **Gate**：大三择校调研时若目标院校机试明确偏好 C++（部分 985），大三寒假花 2-3 周过渡——有 C + Java 基础，语法迁移成本低，无需现在投入

## 五、Java 后端技能栈（实习线）与 408 反哺

| 后端技能 | 学习内容 | 408 反哺 |
|---|---|---|
| Java SE 补强 | 集合源码（ArrayList/HashMap/ConcurrentHashMap）、泛型、IO | 数据结构应用层 |
| JVM | 内存分区、GC、类加载 | 组成原理：内存 / Cache 局部性 |
| 并发 JUC | 线程池、锁、volatile、CAS | OS：进程线程 / 同步 / 死锁 |
| MySQL | 索引（B+ 树）、事务隔离、锁 | 数据结构 B 树；OS 文件系统 |
| Redis | 数据结构、缓存、持久化 | 数据结构：跳表 |
| 网络 | TCP/IP、HTTP(S) | 408 网络整块 |
| Spring Boot | IoC / AOP / 自动装配 | 无 408 考点，但实习必需 |

> 节奏：阶段 1 完成 Java SE + JVM；阶段 3 完成 并发 / MySQL / Redis / 网络；Spring Boot 在寒假项目 1 边做边学。
