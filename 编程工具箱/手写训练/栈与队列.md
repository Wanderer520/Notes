# 主要思想

- **栈**：LIFO 后进先出，像叠盘子；**队列**：FIFO 先进先出，像排队。
- 顺序栈用数组 + top 指针；链栈用单链表**头插法**（见 [[头插法]]）。
- 队列用数组实现必须**循环**（否则假溢出），408 最爱考判满判空与长度公式。
- 在清单中的位置：二叉树非递归遍历 = 栈模拟递归栈；层序 = 队列 BFS；拓扑排序 Kahn 法用队列；表达式求值/括号匹配是 408 栈应用常客。

# 代码实现

```c
#include <stdio.h>
#include <stdlib.h>
#define MAXSIZE 100

/* ---------- 顺序栈：top 指向栈顶元素，空栈 top = -1 ---------- */
typedef struct { int data[MAXSIZE]; int top; } SqStack;

int StackEmpty(SqStack S) { return S.top == -1; }
int StackFull(SqStack S)  { return S.top == MAXSIZE - 1; }
int Push(SqStack *S, int x) {
    if (StackFull(*S)) return 0;        // 满则失败
    S->data[++S->top] = x;
    return 1;
}
int Pop(SqStack *S, int *x) {
    if (StackEmpty(*S)) return 0;
    *x = S->data[S->top--];
    return 1;
}

/* ---------- 链栈：无头结点，头指针即栈顶 ---------- */
typedef struct SNode { int data; struct SNode *next; } SNode, *LinkStack;

int Push(LinkStack *S, int x) {         // 头插
    SNode *p = (SNode*)malloc(sizeof(SNode));
    p->data = x;
    p->next = *S;
    *S = p;
    return 1;
}
int Pop(LinkStack *S, int *x) {
	    if (*S == NULL) return 0;           // 空栈
    SNode *p = *S;
    *x = p->data;
    *S = p->next;
    free(p);
    return 1;
}

/* ---------- 循环队列：front 指向队头，rear 指向队尾的下一个（牺牲一个单元判满） ---------- */
typedef struct { int data[MAXSIZE]; int front, rear; } SqQueue;

int QueueEmpty(SqQueue Q) { return Q.front == Q.rear; }                // 队空
int QueueFull(SqQueue Q)  { return (Q.rear + 1) % MAXSIZE == Q.front; } // 队满
int EnQueue(SqQueue *Q, int x) {
    if (QueueFull(*Q)) return 0;
    Q->data[Q->rear] = x;
    Q->rear = (Q->rear + 1) % MAXSIZE;   // 循环后移
    return 1;
}
int DeQueue(SqQueue *Q, int *x) {
    if (QueueEmpty(*Q)) return 0;
    *x = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAXSIZE;
    return 1;
}
int QueueLen(SqQueue Q) { return (Q.rear - Q.front + MAXSIZE) % MAXSIZE; } // 元素个数
```

# 手写易错点

- **判满 vs 判空最易混**：空 = `front == rear`；满 = `(rear+1) % Max == front`（牺牲一个单元法）。用"队尾追队头差一格就满"来记。
- **长度公式**：`(rear - front + MAXSIZE) % MAXSIZE`——负数取模先加 MAXSIZE。
- 顺序栈 top 约定：王道用 **top = -1 指向栈顶元素**（先 ++ 再存）；另一种 top = 0 指向栈顶下一个，别混。
- 链栈 push/pop 都是头插头删，**不需要判满**，只需判空。
- 入队：先存值再移动 rear；出队：先取值再移动 front。顺序反了就是经典 bug。
- 二叉树遍历用**顺序栈**即可（栈深 = 树高）；层序用循环队列（容量 ≥ 最大宽度）。
