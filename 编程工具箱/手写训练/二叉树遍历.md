# 二叉树遍历

> 手写训练第 1 项（树清单 1/8）：前/中/后序 递归 + 非递归（栈）、层序（队列）
> 三遍法进度：- [ ] 第 1 遍 跟抄　- [ ] 第 2 遍 关书手写　- [ ] 第 3 遍 脱稿默写（__月__日）

# 主要思想

- 三种深度优先遍历的**递归版**是模板，必须能默写；非递归版用**栈模拟递归栈**，408 大题和面试手写常考。
- 核心直觉：**递归序**——递归遍历时每个节点会被"经过"三次（进左子树前 / 左右之间 / 出右子树后）。前序 = 第 1 次经过时打印，中序 = 第 2 次，后序 = 第 3 次。
- 前序/中序非递归是**同一套"一路向左"骨架**，只是访问位置不同：前序入栈前访问，中序出栈后访问——记住这个骨架，两种一起默写。
- 后序非递归用**双栈法**：后序 = 前序变体"根右左"的逆序，改压栈顺序 + 辅助栈即可，最好写。
- 层序 = BFS，用**队列**：出队一个、打印、入其左右孩子。

## 复杂度

| 遍历 | 时间 | 空间 | 说明 |
|---|---|---|---|
| 递归前/中/后序 | O(n) | O(h) | h 为树高，递归栈深度 |
| 非递归前/中序 | O(n) | O(h) | 显式栈 |
| 非递归后序（双栈） | O(n) | O(n) | S2 存全部节点 |
| 层序 | O(n) | O(w) | w 为最大宽度，≤ n/2 |

# 代码实现

```c
#include <stdio.h>
#include <stdlib.h>
#define MAXSIZE 100

/* ---------- 结构定义 ---------- */
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;   // 左右孩子指针
} BiTNode, *BiTree;

void visit(BiTree p) { printf("%d ", p->data); }

/* ---------- 辅助栈 / 队列（数组模拟；考场上可只写 Push/Pop 等函数名） ---------- */
typedef struct { BiTree data[MAXSIZE]; int top; }   SqStack;  // top 指向栈顶
typedef struct { BiTree data[MAXSIZE]; int front, rear; } SqQueue; // rear 指向队尾下一个

void InitStack(SqStack *S)   { S->top = -1; }
int  StackEmpty(SqStack S)   { return S.top == -1; }
void Push(SqStack *S, BiTree p) { S->data[++S->top] = p; }
BiTree Pop(SqStack *S)       { return S->data[S->top--]; }

void InitQueue(SqQueue *Q)   { Q->front = Q->rear = 0; }
int  QueueEmpty(SqQueue Q)   { return Q.front == Q.rear; }
void EnQueue(SqQueue *Q, BiTree p) { Q->data[Q->rear++] = p; }
BiTree DeQueue(SqQueue *Q)   { return Q->data[Q->front++]; }

/* ---------- 递归版：三件套，只差 visit 位置 ---------- */
void PreOrder(BiTree T) {
    if (T == NULL) return;
    visit(T);                  // 第 1 次经过：前序
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}
void InOrder(BiTree T) {
    if (T == NULL) return;
    InOrder(T->lchild);
    visit(T);                  // 第 2 次经过：中序
    InOrder(T->rchild);
}
void PostOrder(BiTree T) {
    if (T == NULL) return;
    PostOrder(T->lchild);
    PostOrder(T->rchild);
    visit(T);                  // 第 3 次经过：后序
}

/* ---------- 非递归前序：一路向左，入栈前访问 ---------- */
void PreOrder2(BiTree T) {
    SqStack S; InitStack(&S);
    BiTree p = T;
    while (p || !StackEmpty(S)) {
        if (p) {
            visit(p);          // 先访问
            Push(&S, p);
            p = p->lchild;     // 向左钻到底
        } else {
            p = Pop(&S);
            p = p->rchild;     // 左到头了，转向右子树
        }
    }
}

/* ---------- 非递归中序：同一骨架，出栈后访问 ---------- */
void InOrder2(BiTree T) {
    SqStack S; InitStack(&S);
    BiTree p = T;
    while (p || !StackEmpty(S)) {
        if (p) {
            Push(&S, p);
            p = p->lchild;
        } else {
            p = Pop(&S);
            visit(p);          // 左子树访问完，访问根
            p = p->rchild;
        }
    }
}

/* ---------- 非递归后序：双栈法 = "根右左" 的逆序 ---------- */
void PostOrder2(BiTree T) {
    SqStack S1, S2; InitStack(&S1); InitStack(&S2);
    if (T) Push(&S1, T);
    while (!StackEmpty(S1)) {
        BiTree p = Pop(&S1);
        Push(&S2, p);          // 不打印，压入 S2
        if (p->lchild) Push(&S1, p->lchild);   // 先左后右 → S2 弹出即"左右根"
        if (p->rchild) Push(&S1, p->rchild);
    }
    while (!StackEmpty(S2)) visit(Pop(&S2));
}

/* ---------- 层序：队列，BFS ---------- */
void LevelOrder(BiTree T) {
    SqQueue Q; InitQueue(&Q);
    if (T) EnQueue(&Q, T);
    while (!QueueEmpty(Q)) {
        BiTree p = DeQueue(&Q);
        visit(p);
        if (p->lchild) EnQueue(&Q, p->lchild);
        if (p->rchild) EnQueue(&Q, p->rchild);
    }
}
```

# 手写易错点

- 递归终止条件：判 `T == NULL` 就 return，**不是**判左右孩子。
- 中序非递归：出栈访问后**必须** `p = p->rchild`，忘了就死循环。
- 前序非递归入栈顺序：先右后左（栈 LIFO）；后序双栈反过来：先左后右。
- 双栈法：S1 弹出时**不要打印**，全部进 S2，最后统一弹 S2。
- 层序：判空用 `while (!QueueEmpty(Q))`，出队后先打印再入孩子。
- 边界：空树（T 为 NULL 直接返回）、单节点树。

# 扩展：由先序 + 中序还原二叉树（408 高频大题）

先序第一个元素是根，在中序里定位根后，左边是左子树、右边是右子树，递归分治：

```c
/* pre[pl..pr] 先序序列，in[il..ir] 中序序列，返回根 */
BiTree build(int pre[], int pl, int pr, int in[], int il, int ir) {
    if (pl > pr) return NULL;
    BiTree root = (BiTree)malloc(sizeof(BiTNode));
    root->data = pre[pl];            // 先序第一个是根
    int k = il;
    while (in[k] != pre[pl]) k++;    // 中序中定位根
    int leftLen = k - il;            // 左子树长度
    root->lchild = build(pre, pl + 1, pl + leftLen, in, il, k - 1);
    root->rchild = build(pre, pl + leftLen + 1, pr, in, k + 1, ir);
    return root;
}
```
