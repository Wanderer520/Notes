# 自托管服务（兴趣摸底项目）

> 起点 2026.09（大二上）· 起步路线：**本机 WSL2 + Docker** · 第一个服务：Gitea（托管笔记库）
> 定位：**一次摸底测试**，不是学习计划的一部分。学习规划（实习/考研）由另一个窗口负责——本项目**不改 `学习规划/` 下的文件**。

## 一、为什么做这个（诊断结论）
- 近期学习全是**输入型**：数据结构"重学"、读 JDK 源码、刷题；没有产出，反馈周期以月/年计 → 越学越没兴趣
- 但"捣鼓电脑各种东西挺乐意"、写代码进入状态也能连着写几小时 → **兴趣没死，缺的是"属于自己的、现在就有用的东西"**
- **摸底探针**（跑通后回答）：① 有没有自己想加下一个东西　② 卡住时是烦躁放弃还是想弄明白　③ 整个过程是"爽"还是"又一件任务"

## 三、起步五步（本机）
1. 前提：Win10 2004+ / Win11、内存 ≥8G、BIOS 虚拟化开启
2. PowerShell：`wsl --install -d Ubuntu`（装完重启）
3. Ubuntu 内写 `/etc/wsl.conf` 开 systemd（`[boot]` → `systemd=true`），`wsl --shutdown` 后重进
4. 装 Docker Engine：`curl -fsSL https://get.docker.com | sudo sh`；`sudo usermod -aG docker $USER`
5. 写 `docker-compose.yml` 跑 Gitea（卷 `./gitea:/data`，端口 3000 网页 + 2222 git-ssh）→ `docker compose up -d` → 开 `http://localhost:3000` → 推送笔记库

## 四、坑与概念
- **国内必踩**：Docker Hub 拉镜像超时 → 把阿里云容器镜像加速地址写进 `/etc/docker/daemon.json`，`systemctl restart docker`
- 大陆服务器 + 域名走 80/443 需要 **ICP 备案**（1-3 周）；本阶段不涉及，后续再评估
- 校园网通常要认证、封入站、NAT 后面 → 宿舍旧机器方案排最后
- 必须讲清的概念：镜像 / 容器 / 卷的区别、端口映射、数据持久化（删容器数据还在）
