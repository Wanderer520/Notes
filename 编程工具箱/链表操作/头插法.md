#链表
# 主要思想
**头插法**：每次把新节点插入到链表的**头部**（头节点 `head` 之后）。

```
head -> A -> B -> C       原链表
head -> p -> A -> B -> C  头插节点 p 后
```

与**尾插法**（依次接到末尾，保持原顺序）相反，头插法会**颠倒遍历顺序**：

- 依次把原链表的节点摘下来，头插到新链表 → 遍历顺序被反转。
- 因此头插法的典型用途是**链表反转**和**逆序构造结果链表**。

# 代码实现
假设带头节点的链表（`head` 是哨兵节点，不存数据）：

```java
// 把节点 p 头插到链表中
public void insert(Node p) {
    p.next = head.next; // 新节点指向原第一个节点
    head.next = p;      // 头节点指向新节点
}
```

注意顺序：**先连 `p.next`，再改 `head.next`**。如果反过来，原链表就丢了。
