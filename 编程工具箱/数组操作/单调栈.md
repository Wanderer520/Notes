#单调栈 #栈 #数组
# 主要思想
**单调栈**：栈内元素保持**单调**（从栈底到栈顶递增或递减）的栈。最经典的用途是求"数组中每个元素**下一个更大/更小元素**"。

以"**下一个更大元素**"为例（从右往左遍历）：

1. 栈里存**下标**，保证从栈底到栈顶对应的**值严格递减**；
2. 遍历到 `i` 时，把栈中所有"值 ≤ `nums[i]`"的下标**弹出**——它们对更左边的位置来说，`nums[i]` 更大且更近，永远不可能成为答案；
3. 弹完后，栈顶就是 `i` **右侧第一个比 `nums[i]` 大**的元素下标；
4. 把 `i` 入栈，作为左侧元素的候选。

**为什么正确**：单调性保证栈里留下的都是"未被淘汰的候选"，栈顶永远是距离最近的那个；每个元素最多入栈一次、出栈一次，所以**时间复杂度 O(n)**（空间 O(n)）。

> 变体思路：找"下一个更小元素"只需把弹出条件反过来（弹出"值 ≥ 当前值"的），见例题 [[商品折扣后的最终价格]]。

# 代码实现
"下一个更大元素"模板（以 [[每日温度]] 为例，答案存**距离**）：

```java
// 返回数组 ans，ans[i] = i 右侧第一个比 nums[i] 大的元素的距离；不存在则为 0
public int[] nextGreater(int[] nums) {
    int n = nums.length;
    int[] ans = new int[n];
    Deque<Integer> stack = new ArrayDeque<>(); // 存下标，栈底到栈顶对应值严格递减
    for (int i = n - 1; i >= 0; i--) {
        while (!stack.isEmpty() && nums[i] >= nums[stack.peek()]) {
            stack.pop(); // 右侧 ≤ nums[i] 的都被淘汰
        }
        ans[i] = stack.isEmpty() ? 0 : stack.peek() - i;
        stack.push(i);
    }
    return ans;
}
```

关键点：
- 弹出条件 `nums[i] >= nums[stack.peek()]` 里的 `>=` 保证重复元素也能正确找到"下一个更大"；
- 存下标而不是存值，才能算出距离。

# 例题
- [[每日温度]]：经典"下一个更大元素"，答案存距离（对应上面模板）
