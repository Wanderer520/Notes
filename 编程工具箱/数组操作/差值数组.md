#数组 #Java
# 主要思想
**差值数组**：`d[i] = nums[i+1] - nums[i]`，相当于原数组的"变化率"。

- `d[i] == 0` ⇔ `nums[i]` 与 `nums[i+1]` **相等**（没有变化）
- `d[i] != 0` ⇔ 相邻元素发生了**变化**

因此，"连续相等元素"问题可以转化为"差值数组中连续 0 的个数"问题：
一段连续相等的元素（长度 k）在 `d[]` 中对应 **k−1 个连续的 0**。

> ⚠️ 差值数组的长度是 `n−1`（最后一个元素没有后继，不需要处理；这样也不会把"延伸到末尾的相等段"多算）。

# 代码实现
给定 `nums[n]`，求最大连续相等元素的个数：

```java
// 1. 构造差值数组
int[] d = new int[n - 1];
for (int i = 0; i < n - 1; i++) {
    d[i] = nums[i + 1] - nums[i];
}

// 2. 统计 d[] 中连续 0 的最大个数
int max = 0;   // 连续 0 的最大个数
int count = 0; // 当前连续 0 的个数
for (int i = 0; i < n - 1; i++) {
    if (d[i] == 0) {
        count++;
        if (max < count) max = count;
    } else {
        count = 0;
    }
}

// 3. 连续相等元素的最大个数 = 连续 0 的个数 + 1
int ans = max + 1;
```

# 例题
## 1. 最大连续 1 的个数
给定一个二进制数组 `nums` ，计算其中最大连续 `1` 的个数。

**示例 1：**

**输入：**nums = [1,1,0,1,1,1]
**输出：**3
**解释：**开头的两位和最后的三位都是连续 1 ，所以最大连续 1 的个数是 3.

**示例 2:**

**输入：**nums = [1,0,1,1,0,1]
**输出：**2

**提示：**

- `1 <= nums.length <= 105`
- `nums[i]` 不是 `0` 就是 `1`.

本题元素只有 0/1 两种，**直接计数**即可（遇到 0 清零，否则累加），不需要真的构造差值数组——思路一致：`nums[i] == nums[i+1]` ⇔ 差值 0：

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        int max = 0;   // 历史最大连续 1 的个数
        int count = 0; // 当前连续 1 的个数
        for (int i = 0; i < nums.length; i++) {
            count++;
            if (nums[i] == 0)
                count = 0;          // 遇到 0 清零
            if (max < count)
                max = count;
        }
        return max;
    }
}
```

## 2. 错误的集合
集合 `s` 包含从 `1` 到 `n` 的整数。不幸的是，因为数据错误，导致集合里面某一个数字复制成了集合里面的另外一个数字的值，导致集合 **丢失了一个数字** 并且 **有一个数字重复** 。

给定一个数组 `nums` 代表了该集合发生错误后的结果。请你找出重复出现的整数，再找到丢失的整数，将它们以数组的形式返回。

**示例 1：**

**输入：**nums = [1,2,2,4]
**输出：**[2,3]

**示例 2：**

**输入：**nums = [1,1]
**输出：**[1,2]

**提示：**

- `2 <= nums.length <= 104`
- `1 <= nums[i] <= 104`

本题是差值数组的典型应用：排序后，相邻元素差值 `d[i] == 0` 说明**重复**；`d[i] == 2` 说明中间**缺了一个数**：

```java
public int[] findErrorNums(int[] nums) {
    int[] d = new int[nums.length];
    int[] error = new int[2];

    Arrays.sort(nums); // 排序后，重复与缺失都体现在相邻差值上

    // 构造差值数组：最后一个元素"后继"视为 n+1，用于捕捉缺失 n 的情况
    for (int i = 0; i < nums.length; i++) {
        if (i == nums.length - 1)
            d[i] = nums.length + 1 - nums[nums.length - 1];
        else
            d[i] = nums[i + 1] - nums[i];
    }

    for (int i = 0; i < nums.length; i++) {
        if (d[i] == 0) {          // 差值为 0：重复
            error[0] = nums[i];
        }
        if (d[i] == 2) {          // 差值为 2：缺失
            error[1] = nums[i] + 1;
        }
    }

    // 特殊情况：缺失的是 1（此时数组从 2 开始，前面的差值检测不到）
    if (error[1] == 0)
        error[1] = 1;

    return error;
}
```
