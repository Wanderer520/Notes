# 主要思想
例如给定数组nums[n],求最大连续（相同）数的个数
1.求数组d[n]
```java
`for(int i=0 ; i<n ; i++){`
	`if(i==n-1)`
		`d[i]=0;`
	`else`
		`d[i]=nums[i+1]-nums[i];`	
`}`
```
2.求最大连续（相同）数的个数
	数组d[]可看似为nums[]的变化率，为零时不变，所以我们可以

```java
	`int max=0;`	
	`int count=0;`
	`for(int i=0;i<n;i++){`
		`count++;`
            `if(nums[i]==0)`
                `count=0;`
            `if(max<count)`
                `max=count;`
	`}`
```
	max即为所求
# 例题：
## 1.
给定一个二进制数组 `nums` ， 计算其中最大连续 `1` 的个数。 ^5312c7

**示例 1：**

**输入：**nums = [1,1,0,1,1,1]
**输出：**3
**解释：**开头的两位和最后的三位都是连续 1 ，所以最大连续 1 的个数是 3.

**示例 2:**

**输入：**nums = [1,0,1,1,0,1]
**输出：**2

**提示：**

- `1 <= nums.length <= 105`
- `nums[i]` 不是 `0` 就是 `1`.
```java
`/**`  
 * `查找数组中最大连续 1 的个数`  
 *  
 * `@param nums 只包含 0 和 1 的整型数组`  
 * `@return 最大连续 1 的个数`  
 `**/`  
`class Solution {`  
    `public int findMaxConsecutiveOnes(int[] nums) {`  
        `// 记录历史最大连续 1 的个数`  
        `int max=0;`  
        `// 记录当前连续 1 的个数`  
        `int count=0;`  
  
        `// 遍历数组元素`  
        `for(int i=0;i<nums.length;i++){`  
            `count++;`  
  
            `// 遇到 0 则当前连续计数清零`  
            `if(nums[i]==0)`  
                `count=0;`  
  
            `// 更新最大连续个数`  
            `if(max<count)`  
                `max=count;`  
        `}`  
        `return max;`  
    `}`  
`}`
```

## 2.
集合 `s` 包含从 `1` 到 `n` 的整数。不幸的是，因为数据错误，导致集合里面某一个数字复制成了集合里面的另外一个数字的值，导致集合 **丢失了一个数字** 并且 **有一个数字重复** 。

给定一个数组 `nums` 代表了该集合发生错误后的结果。

请你找出重复出现的整数，再找到丢失的整数，将它们以数组的形式返回。

**示例 1：**

 **输入：**nums = [1,2,2,4]
**输出：**[2,3] 

**示例 2：**

**输入：**nums = [1,1]
**输出：**[1,2]

**提示：**

- `2 <= nums.length <= 104`
- `1 <= nums[i] <= 104`

```java
`/**`  
 * `查找数组中重复的数字和缺失的数字`  
 * `数组包含 1 到 n 的整数，其中恰好有一个数字重复，一个数字缺失`  
 *  
 * `@param nums 包含 1 到 n 整数的数组`  
 * `@return 长度为 2 的整型数组，索引 0 为重复的数字，索引 1 为缺失的数字`  
 `*/`  
`public int[] findErrorNums(int[] nums) {`  
    `// 初始化差值数组和存储结果的数组`  
    `int[] d=new int[nums.length];`  
    `int[] error=new int[2];`  
      
    ``// 对数组排序，便于通过相邻元素差值判断重复和缺失``  
    ``Arrays.sort(nums);``  
      
    ``// 计算相邻元素的差值，处理最后一个元素的边界情况``  
    ``for(int i=0;i<nums.length;i++){``  
        ``if(i==nums.length-1)``  
            ``d[i]=nums.length+1-nums[nums.length-1];``  
        ``else``  
            ``d[i]=nums[i+1]-nums[i];``  
    ``}``  
      
    ``// 遍历差值数组，差值为 0 表示重复，差值为 2 表示缺失``  
    ``for(int i=0;i<nums.length;i++){``  
        ``if(d[i]==0){``  
            ``error[0]=nums[i];``  
        ``}``  
        ``if(d[i]==2){``  
            ``error[1]=nums[i]+1;``  
        ``}``  
    ``}``  
      
    ``// 处理缺失数字为 1 的特殊情况``  
    ``if(error[1]==0)``  
        ``error[1]=1;``  
          
    ``// 返回结果数组``  
    ``return error;``  
`}`
```
