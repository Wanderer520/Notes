#滑动窗口 #双指针 #数组 #字符串
# 主要思想
**滑动窗口**：两个指针 `left`、`right` 维护一个**连续区间**（窗口），`right` 负责**扩张**，`left` 负责**收缩**，让窗口始终满足某个约束，在过程中更新答案。属于**同向双指针**（两个指针都只往右走）。

核心框架：

1. `right` 每次右移一格，把新元素纳入窗口；
2. 只要窗口**不满足约束**，就移动 `left` 收缩窗口，直到约束重新满足；
3. 在窗口合法时更新答案。

**为什么是 O(n)**：`left`、`right` 都只向右移动，每个元素最多被加入一次、移出一次，均摊 O(n)——相比暴力的 O(n²) 枚举所有子串，省掉的是"重复扫描"。

> **为什么"像 KMP"**：遇到冲突（如字符重复）时不 reset 重来，而是平移边界继续，这正是 KMP 不回溯思想的同款基因。区别：KMP 的平移量靠预计算好的 `next[]`，滑动窗口的平移量由窗口内容实时决定。

# 代码实现
"最长满足约束的子串"通用模板（以"无重复字符"为例，见 [[无重复字符的最长子串]]）：

```cpp
#include <unordered_map>
#include <string>
#include <algorithm>

int longestWithoutRepeat(const std::string& s)
{
    int ans = 0;
    std::unordered_map<char, int> cnt; // 窗口内每个字符的出现次数
    for (int left = 0, right = 0; right < (int)s.length(); right++)
    {
        cnt[s[right]]++;
        while (cnt[s[right]] > 1)   // 约束：每个字符最多出现 1 次
        {
            cnt[s[left]]--;
            left++;                  // 收缩左边界，直到约束重新满足
        }
        ans = std::max(ans, right - left + 1); // 窗口合法时更新答案
    }
    return ans;
}
```

关键点：
- 求**最长**：先让窗口合法，再更新答案；
- 求**最短**（如长度最小的子数组 LC 209）：窗口合法时**先尝试收缩再更新**，答案更新放在 while 内部；
- `while` 比 `if` 通用——换成"最多 k 个不同字符"时 `while` 原样可用，`if` 不行。

# 变体（以后遇到再补）
- **最多 k 个不同字符**（LC 340）：`while` 条件换成"不同字符数 > k"，需额外维护种类计数；
- **最小覆盖子串**（LC 76）：`while` 条件换成"窗口已覆盖 t 的所有字符"，答案在 while 内部更新；
- **长度最小的子数组**（LC 209）：`while` 条件换成"窗口和 ≥ target"。
