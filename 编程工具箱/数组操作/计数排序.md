#数组 #排序 #计数排序 #Java
# 主要思想
当我们需要记录某些数字**出现的次数**时，可以用**计数排序**的思想：

1. 创建一个数组 `int[] cnt`，**下标 = 数字本身**，**元素值 = 该数字出现的次数**；
2. 遍历目标数组，遇到数字 `x` 就让 `cnt[x]++`；
3. 统计完成后，`cnt` 天然有序——按下标从小到大就是所有数字的计数。

再配合**前缀和**（`cnt[i] += cnt[i-1]`），`cnt[i]` 就变成"小于等于 i 的数字总数"，可以 O(1) 回答"有多少数字比 x 小"这类问题。

适用条件：数字的取值范围（值域）不能太大，否则 `cnt` 数组会很大。

# 代码实现
- `nums`：目标数组，元素一般为**非负整数**
- `n`：`nums` 的最大值（决定 `cnt` 的长度）

```java
// 统计每个数字出现的次数
public static int[] solution(int[] nums) {
    int[] cnt = new int[n + 1]; // 下标 0..n
    for (int i = 0; i < nums.length; i++)
        cnt[nums[i]]++;
    return cnt;
}
```
