# 思路 
#计数排序 
### 当我们需要记录某些数字出现的次数时，我们可以使用计数排序

##### 我们先创造一个数组int[] cnt，数组下标为对应数字，元素值为对应数字出现的次数
这样只需要遍历目标数组，遇到数字使cnt数组对应下标的值增加就成功记录了每个数字出现的次数
# 代码实现
### 部分变量意义解释
nums为目标数组，一般都大于等于
n为nums最大值
```java
	public static int[] solution(int[] nums){
		int[] cnt=new int[n+1];
		for(int i=0;i<nums.length;i++)
			cnt[nums[i]]++;
		return cnt;
	}
```
