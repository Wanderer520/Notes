#栈 #字符串 #LeetCode
# 题干
给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

**输入：**s = "()"

**输出：**true

**示例 2：**

**输入：**s = "()[]{}"

**输出：**true

**示例 3：**

**输入：**s = "(]"

**输出：**false

**示例 4：**

**输入：**s = "([])"

**输出：**true

**示例 5：**

**输入：**s = "([)]"

**输出：**false

**提示：**

- `1 <= s.length <= 104`
- `s` 仅由括号 `'()[]{}'` 组成

# 我的题解
思路：**栈**。用栈保存待匹配的左括号，栈顶始终是"最近出现、还未匹配"的括号。

- 遇到**左括号** → 入栈，等待后续配对；
- 遇到**右括号** → 检查栈顶是否是对应的左括号：是则弹出（配对成功），否则说明类型不匹配或没有可配对的左括号，直接返回 `false`；
- 遍历结束后，栈为空说明全部配对成功，否则说明有多余的左括号。

时间复杂度 O(n)，空间复杂度 O(n)（栈最多存 n 个字符）。

```java
class Solution {
    public boolean isValid(String s) {
        // 用栈保存待匹配的左括号，栈顶 = 最近出现、还未匹配的括号
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (stack.isEmpty()) {
                // 栈为空时只有左括号能入栈；右括号没有左括号可匹配，直接返回 false
                if (c == '(' || c == '[' || c == '{') {
                    stack.push(c);
                } else {
                    return false;
                }
                continue;
            }

            char top = stack.peek(); // 最近一个未匹配的左括号

            if (c == ')') {          // 右小括号：栈顶必须是左小括号
                if (top == '(') {
                    stack.pop();     // 匹配成功，弹出
                } else {
                    return false;    // 类型不匹配
                }
            } else if (c == ']') {   // 右中括号：栈顶必须是左中括号
                if (top == '[') {
                    stack.pop();
                } else {
                    return false;
                }
            } else if (c == '}') {   // 右大括号：栈顶必须是左大括号
                if (top == '{') {
                    stack.pop();
                } else {
                    return false;
                }
            } else {                 // 左括号：入栈等待匹配
                stack.push(c);
            }
        }

        // 遍历结束栈为空 => 所有括号都匹配成功
        return stack.isEmpty();
    }
}
```

# 官方题解
思路：判断括号的有效性可以使用「栈」。遍历字符串时，遇到左括号就将其入栈（后遇到的左括号要先闭合，所以左括号放在栈顶）；遇到右括号时取出栈顶的左括号，判断是否同类型。为了快速判断类型，用哈希表存储"右括号 → 对应左括号"的映射：遇到右括号时，若栈为空或栈顶不是映射中对应的左括号，则无效，直接返回 `False`。遍历结束后栈为空说明全部闭合，返回 `True`。

注意：有效字符串的长度一定为偶数，因此**若长度为奇数可直接返回 `False`**，省去遍历。

时间复杂度 O(n)，空间复杂度 O(n)（哈希表 + 栈）。

```java
// 官方代码
public boolean isValid(String s) {
        int n = s.length();
        if (n % 2 == 1) {
            return false;
        }

        Map<Character, Character> pairs = new HashMap<Character, Character>() {{
            put(')', '(');
            put(']', '[');
            put('}', '{');
        }};
        Deque<Character> stack = new LinkedList<Character>();
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            if (pairs.containsKey(ch)) {
                if (stack.isEmpty() || stack.peek() != pairs.get(ch)) {
                    return false;
                }
                stack.pop();
            } else {
                stack.push(ch);
            }
        }
        return stack.isEmpty();
    }
```
