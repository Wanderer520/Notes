# 题干
**题目**：P1739 表达式括号匹配（洛谷）
> 题目链接：https://www.luogu.com.cn/problem/P1739

假设一个表达式由数字、英文字母（小写）、运算符（`+`、`-`、`*`、`/`）和左右小（圆）括号构成，以 `@` 作为表达式的结束符。请编写一个程序检查表达式中的左右圆括号是否匹配，若匹配，则输出 `YES`；否则输出 `NO`。表达式长度小于 255，左圆括号少于 20 个。

## 输入格式

一行：表达式。

## 输出格式

一行：`YES` 或 `NO`。

## 输入输出样例

**输入 #1**

```
2*(x+y)/(1-x)@
```

**输出 #1**

```
YES
```

**输入 #2**

```
(25+x)*(a*(a+b+b)@
```

**输出 #2**

```
NO
```

## 说明/提示

表达式长度小于 255，左圆括号少于 20 个。

# 我的题解
思路：和 [[有效的括号]]（LC20）同一招——**栈匹配**。区别在于：本题表达式里只有圆括号 `()`，且混着数字、字母、运算符和结束符 `@`，所以只处理 `(` 和 `)`，其余字符直接跳过，遇到 `@` 停止。

- 遇到 `(` → 入栈；
- 遇到 `)` → 栈顶必须是 `(`：是则弹出配对，否则（栈空或栈顶不是 `(`）直接判不匹配；
- 遍历结束栈为空 → 全部匹配，输出 `YES`。

时间复杂度 O(n)，空间复杂度 O(n)。

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String s = in.next(); // 表达式以 @ 结束
        System.out.println(isValid(s) ? "YES" : "NO");
    }

    public static boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '@') break;            // 结束符，停止扫描
            if (c == '(') {
                stack.push(c);              // 左括号入栈，等待配对
            } else if (c == ')') {
                // 右括号：栈空 = 没有左括号可配；栈顶不是 '(' = 顺序错误
                if (stack.isEmpty() || stack.pop() != '(') {
                    return false;
                }
            }
            // 数字、字母、运算符直接忽略
        }
        return stack.isEmpty();             // 栈空 => 全部匹配
    }
}
```

# 官方题解
> 洛谷此题只有通过审核的**民间题解**（题解区），非官方题解。

思路：此题用栈即可。栈是后进先出的数据结构，可以在栈顶入栈/出栈。遍历字符串：遇到左括号入栈；遇到右括号时，若栈非空且栈顶是左括号则弹出，否则不匹配，直接输出 `NO` 并结束；遍历结束后若栈为空输出 `YES`，否则输出 `NO`。

```c++
#include<bits/stdc++.h>
using namespace std;
string a;
stack<char>stk;
signed main(){
    cin>>a;
    for(int i=0;i<a.size();i++){
        if(a[i]=='('){
            stk.push('(');
        }
        if(a[i]==')'){
            if((!stk.empty())&&stk.top()=='('){
                stk.pop();
            }
            else{
                cout<<"NO";
                return 0;
            }
        }
    }
    if(stk.empty()) cout<<"YES";
    else cout<<"NO";
    return 0;
}
```
