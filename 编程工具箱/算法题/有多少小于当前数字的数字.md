# 题干
#数组 #LeetCode
给你一个数组 `nums`，对于其中每个元素 `nums[i]`，请你统计数组中比它小的所有数字的数目。

换而言之，对于每个 `nums[i]` 你必须计算出有效的 `j` 的数量，其中 `j` 满足 `j != i` **且** `nums[j] < nums[i]` 。

以数组形式返回答案。

**示例 1：**

**输入：**nums = [8,1,2,2,3]
**输出：**[4,0,1,1,3]
**解释：** 
对于 nums[0]=8 存在四个比它小的数字：（1，2，2 和 3）。 
对于 nums[1]=1 不存在比它小的数字。
对于 nums[2]=2 存在一个比它小的数字：（1）。 
对于 nums[3]=2 存在一个比它小的数字：（1）。 
对于 nums[4]=3 存在三个比它小的数字：（1，2 和 2）。

**示例 2：**

**输入：**nums = [6,5,4,8]
**输出：**[2,1,0,3]

**示例 3：**

**输入：**nums = [7,7,7,7]
**输出：**[0,0,0,0]

**提示：**

- `2 <= nums.length <= 500`
- `0 <= nums[i] <= 100`

# 我的题解
#暴力
```java
/**  
 * 计算数组中每个元素对应的"小于当前元素的数字个数"  
 ** 对于数组中的每个元素，统计其他位置中小于该元素的数字数量  
 *   
* @param nums 输入的整数数组  
 * @return 返回一个数组，其中每个位置的值表示原数组对应位置元素中有多少个元素小于它  
 */  
class Solution {  
    public int[] smallerNumbersThanCurrent(int[] nums) {  
        int[] arr=new int[nums.length];  
        for(int i=0;i<nums.length;i++){  
            int count=0;  
            // 遍历整个数组，统计小于当前元素nums[i]的元素个数  
            for(int j=0;j<nums.length;j++)  
                if(nums[j]<nums[i])  
                    count++;  
            arr[i]=count;  
        }  
        return arr;  
    }  
}
```
# 官方题解
## 排序
#多维数组自定义排序
```java
/**  
 * 计算数组中每个元素对应的"小于当前元素的数字个数"  
 ** 使用排序优化的方法：先将元素值和原始索引一起存储，排序后根据排名确定小于当前元素的个数  
 *   
* @param nums 输入的整数数组  
 * @return 返回一个数组，其中每个位置的值表示原数组对应位置元素中有多少个元素小于它  
 */  
class Solution {  
    public int[] smallerNumbersThanCurrent(int[] nums) {  
        int n = nums.length;  
        // 创建二维数组存储元素值和原始索引的映射关系  
        int[][] data = new int[n][2];  
        for (int i = 0; i < n; i++) {  
            data[i][0] = nums[i];  
            data[i][1] = i;  
        }  
        // 按元素值进行升序排序  
        Arrays.sort(data, new Comparator<int[]>() {  
            public int compare(int[] data1, int[] data2) {  
                return data1[0] - data2[0];  
            }  
        });  
  
        int[] ret = new int[n];  
        int prev = -1;  
        // 根据排序后的位置确定每个元素的结果值，处理重复元素的情况  
        for (int i = 0; i < n; i++) {  
            if (prev == -1 || data[i][0] != data[i - 1][0]) {  
                prev = i;  
            }  
            ret[data[i][1]] = prev;  
        }  
        return ret;  
    }  
}
```
## 计数排序
#计数排序
```java
/**  
 * 计算数组中每个元素对应的"小于当前元素的数字个数"  
 ** 使用计数排序的思想：先统计每个值的出现次数，再计算前缀和得到小于等于每个值的总数，  
 * 最后通过前缀和快速查询小于当前元素的个数  
 *   
* @param nums 输入的整数数组，元素范围在0-100之间  
 * @return 返回一个数组，其中每个位置的值表示原数组对应位置元素中有多少个元素小于它  
 */  
class Solution {  
    public int[] smallerNumbersThanCurrent(int[] nums) {  
        // 统计每个值出现的次数  
        int[] cnt = new int[101];
        int n = nums.length;
        for (int i = 0; i < n; i++) {  
            cnt[nums[i]]++;  
        }  
        // 计算前缀和，cnt[i]表示小于等于i的元素总数  
        for (int i = 1; i <= 100; i++) {  
            cnt[i] += cnt[i - 1];  
        }  
        // 根据前缀和计算结果：小于nums[i]的元素个数为cnt[nums[i]-1]  
        int[] ret = new int[n];  
        for (int i = 0; i < n; i++) {  
            ret[i] = nums[i] == 0 ? 0 : cnt[nums[i] - 1];  
        }  
        return ret;  
    }  
}
```
