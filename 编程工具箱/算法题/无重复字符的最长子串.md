#滑动窗口 #哈希表 #字符串 #双指针 #LeetCode
# 题干
给定一个字符串 `s`，请你找出其中不含有重复字符的**最长子串**的长度。

**示例 1:**

**输入:** s = "abcabcbb"
**输出:** 3 （最长子串 "abc"）

**示例 2:**

**输入:** s = "bbbbb"
**输出:** 1 （最长子串 "b"）

**示例 3:**

**输入:** s = "pwwkew"
**输出:** 3 （最长子串 "wke"，注意不是 "pwke"——**子串要求连续**）

**提示：**

- `0 <= s.length <= 5 * 10^4`
- `s` 由英文字母、数字、符号和空格组成

# 我的题解
思路：**滑动窗口（双指针）+ 哈希表计数**。

- `right` 每次右移一格，把 `s[right]` 计入窗口；
- 若 `s[right]` 在窗口内出现次数 > 1（出现重复），`while` 循环把 `left` **逐格右移**、同步移出对应字符，直到窗口重新合法；
- 窗口合法时用 `right - left + 1` 更新答案。

```cpp
int lengthOfLongestSubstring(std::string s)
{
    int ans = 0;
    std::unordered_map<char, int> charCnt;
    for (int left = 0, right = 0; right < s.length(); right++)
    {
        charCnt[s[right]]++;
        while (charCnt[s[right]] > 1)
        {
            charCnt[s[left]]--;
            left++;
        }
        ans = std::max(ans, right - left + 1);
    }
    return ans;
}
```

复杂度：**O(n)** 均摊——每个字符最多入窗一次、出窗一次；空间 O(字符集大小)。

> **做题时的直觉**：一开始觉得这题像 KMP 的 next 数组，确实有共同内核——"遇到冲突**不从头重来**，而是利用已有信息**平移边界**，避免重复扫描"。区别在于：KMP 的平移量靠**预计算**的 `next[]`（服务于模式匹配），滑动窗口的平移量由**窗口内容实时**决定（服务于维护一个合法区间）。殊途同归到 O(n)，这就是"像"的本质。

# 官方题解
思路：同样是滑动窗口，但哈希表存每个字符**最近一次出现的下标** `last[ch]`。遇到 `s[right]` 之前出现过时，**不逐格收缩**，直接把 `left` 跳到 `max(left, last[s[right]] + 1)`——因为 `last[s[right]]` 及它左边的字符对当前窗口已经没有意义了。

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_map<char, int> last; // 字符 → 最近一次出现的下标
        int ans = 0;
        for (int left = 0, right = 0; right < (int)s.length(); right++) {
            if (last.count(s[right])) {
                left = max(left, last[s[right]] + 1);
            }
            last[s[right]] = right;
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```

两种写法都是 O(n)：
- **我的写法**（while 逐格收缩）是**通用模板**，能直接推广到"最多 k 个不同字符"(LC 340) 等变体；
- **官方写法**（last 下标直接跳跃）是本题特化，常数更小，但只适用于"完全无重复"这类约束。

两种都值得掌握。招式笔记见 [[滑动窗口]]。
