# 题干
设计一个支持 `push`，`pop`，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类：

- `MinStack()` 初始化堆栈对象。
- `void push(int val)` 将元素 `val` 推入堆栈。
- `void pop()` 删除堆栈顶部的元素。
- `int top()` 获取堆栈顶部的元素。
- `int getMin()` 获取堆栈中的最小元素。

**示例 1：**

**输入：**
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

**输出：**
[null,null,null,null,-3,null,0,-2]

**解释：**
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.

**提示：**

- `-231 <= val <= 231 - 1`
- `pop`、`top` 和 `getMin` 操作总是在**非空栈**上调用
- `push`、`pop`、`top` 和 `getMin` 最多被调用 `3 * 104` 次

# 官方题解
> 本题未独立做出（黄区学题解），以下只整理官方解法，**次日关题解复写**。

思路：**双栈**。数据栈 `xStack` 正常存取；辅助栈 `minStack` 同步记录"每个时刻的最小值"——push 时把 `min(新元素, 当前最小值)` 压入，使 `minStack` 栈顶**始终是当前栈的最小值**，`getMin()` 直接取栈顶即为 O(1)。pop 时两个栈一起弹，保证两栈"平行"。

关键技巧：`push(Integer.MAX_VALUE)` 放一个哨兵，避免首次 push 时 `minStack.peek()` 取到空栈。

时间复杂度：push / pop / top / getMin 均 O(1)；空间复杂度 O(n)（两个栈）。

```java
class MinStack {
    private Deque<Integer> xStack;    // 数据栈：正常存取
    private Deque<Integer> minStack;  // 辅助栈：栈顶 = 当前最小值

    public MinStack() {
        xStack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
        minStack.push(Integer.MAX_VALUE); // 哨兵，避免空栈取 min
    }

    public void push(int val) {
        xStack.push(val);
        // 压入"新元素与当前最小值"的较小者，minStack 栈顶始终是最小值
        minStack.push(Math.min(minStack.peek(), val));
    }

    public void pop() {
        xStack.pop();
        minStack.pop(); // 同步弹出，保持两栈平行
    }

    public int top() {
        return xStack.peek();
    }

    public int getMin() {
        return minStack.peek(); // 栈顶就是当前最小值
    }
}
```
