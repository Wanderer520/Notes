#队列 #模拟 #洛谷
# 题干
**题目**：P1996 约瑟夫问题（洛谷）
> 题目链接：https://www.luogu.com.cn/problem/P1996

n 个人（n≤100）围成一圈，从第一个人开始报数，数到 m 的人出列，然后下一个人重新从 1 开始报数，数到 m 的人再出列……如此反复直到所有人都出列。请依次输出出列人的编号。

## 输入格式

一行两个整数 n, m（1 ≤ n, m ≤ 100）。

## 输出格式

依次输出出列人的编号，每两个编号之间用一个空格隔开。

## 输入输出样例

**输入 #1**

```
10 3
```

**输出 #1**

```
3 6 9 2 7 1 8 5 10 4
```

# 我的题解
思路：**队列循环模拟**。队列天然是"环形"的——把队首的人从头移到尾（出队再入队）就等价于"下一个人接着报数"。所以每次把前 m-1 个人依次"从头移到尾"，此时队首正好是数到 m 的人，出队输出即可。

- 初始：1..n 依次入队；
- 每次循环：前 m-1 个人 `出队再入队`，第 m 个人出队输出；
- 重复直到队列为空。

时间复杂度 O(n·m)（每人出队前最多移动 m-1 次），空间复杂度 O(n)。

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int m = in.nextInt();

        Deque<Integer> queue = new ArrayDeque<>();
        for (int i = 1; i <= n; i++) queue.offer(i); // 1..n 入队，队头 = 当前报数的人

        while (!queue.isEmpty()) {
            // 报数到 m：前 m-1 个人从头移到尾（等效于下一个人接着报数）
            for (int i = 0; i < m - 1; i++) {
                queue.offer(queue.poll());
            }
            System.out.print(queue.poll() + " "); // 队首 = 数到 m 的人，出队输出
        }
    }
}
```

# 官方题解
> 洛谷此题只有通过审核的**民间题解**（题解区），非官方题解。

思路：用布尔数组 `visit[]` 标记"已出队"，配合类似取模的循环计数——编号从 1 开始，`++s > n` 就回到 1；遇到已出队的人则 `i--` 多数一次。每数满 m 次输出并标记一个出队者，共出队 n 次。这是不借队列的"纯数组模拟"，与我的队列做法殊途同归。

```c++
#include<cstdio>
using namespace std;
int main()
{
    int n,m,s=0;scanf("%d%d",&n,&m);//读入
    bool visit[200]={0};//visit 标记已出队
    for(int k=0;k<n;k++){//共出队 n 次
        for(int i=0;i<m;i++){if(++s>n)s=1;if(visit[s])i--;}//类似取模循环；遇已出队则 i-- 继续数
        printf("%d ",s);visit[s]=true;//输出并标记出队
    }
    return 0;
}
```

# 扩展
本题要输出**完整出圈顺序**，队列模拟最直接。若只问**最后剩下的人**（面试常见变体），有 O(n) 数学递推：`f(1)=0`，`f(i) = (f(i-1) + m) % i`，答案 `f(n) + 1`。
