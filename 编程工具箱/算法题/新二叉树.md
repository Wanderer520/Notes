# 题干
**题目**：P1305 新二叉树（洛谷）
> 题目链接：https://www.luogu.com.cn/problem/P1305

输入一串二叉树，用遍历前序打出。

## 输入格式

第一行为二叉树的节点数 n（n ≤ 26，节点为一个大写字母）。
后面 n 行，每一个字母为节点，后两个字母分别为其左右儿子。空节点用 `*` 表示。

## 输出格式

前序排列的二叉树。

## 输入输出样例

> 自测样例（原题样例见题目链接）

**输入 #1**

```
5
abc
bde
c**
d**
e**
```

**输出 #1**

```
abdec
```

**输入 #2**（乱序输入：根 a 不在第一行）

```
5
bde
c**
d**
e**
abc
```

**输出 #2**

```
abdec
```

## 说明/提示

- 保证二叉树合法；n ≤ 26，节点为一个大写字母，`*` 表示空节点。

# 我的题解
思路：**字符数组当"指针"用**——`lchild[c]` 存节点 c 的左孩子、`rchild[c]` 存右孩子，`'*'` 表示空，天然就是一棵静态二叉树，不用真的 malloc 建树。前序遍历照旧：先根 → 再左 → 后右。

**关键：根要找，不能默认第一行**。题面没说第一行是根，输入顺序任意（见样例 #2）。办法：读入时把每个"被当成孩子"的节点标记进 `isChild[]`，全部读完后，**没被任何节点当过孩子的那个节点就是根**——树的根没有父节点。

时间复杂度 O(n)，空间复杂度 O(n)（两个 char 数组 + 标记数组，大小固定 128）。

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner cin = new Scanner(System.in);
        char[] lchild = new char[128];
        char[] rchild = new char[128];
        boolean[] isChild = new boolean[128];   // 标记"被当过孩子"
        int n = cin.nextInt();
        String[] lines = new String[n];
        for (int i = 0; i < n; i++) {
            lines[i] = cin.next();
            char node = lines[i].charAt(0);     // 每行格式：节点 左儿子 右儿子
            lchild[node] = lines[i].charAt(1);
            rchild[node] = lines[i].charAt(2);
            if (lchild[node] != '*') isChild[lchild[node]] = true;
            if (rchild[node] != '*') isChild[rchild[node]] = true;
        }
        char root = 0;
        for (int i = 0; i < n; i++) {           // 找根：没被当过孩子的节点
            char node = lines[i].charAt(0);
            if (!isChild[node]) { root = node; break; }
        }
        PreOrder(lchild, rchild, root);
    }

    public static void PreOrder(char[] lchild, char[] rchild, char root) {
        if (root == '*' || root == '\0')        // 空孩子，返回
            return;
        System.out.print(root);                 // 前序：先根
        PreOrder(lchild, rchild, lchild[root]); // 再左
        PreOrder(lchild, rchild, rchild[root]); // 后右
    }
}
```

> 坑：初版写的 `if (root == '*') root = node;` 是默认**第一行就是根**，输入乱序（样例 #2）会从错误节点开始输出 `bde`。改成找根版后任意输入都对（已用随机乱序数据验证 3000 棵）。

# 官方题解
> 洛谷此题只有通过审核的**民间题解**（题解区），非官方题解。与我的 Java 版同构：先找根，再递归前序（遍历每一行找以当前节点为根的行）。

```c++
#include <bits/stdc++.h>
using namespace std;
int n;
string s[30];
bool vis[128];                          // 被当过孩子则标记

void dfs(char r) {
    cout << r;                          // 前序：先根
    for (int i = 0; i < n; i++) {       // 找到以 r 为根的那一行
        if (s[i][0] == r) {
            if (s[i][1] != '*') dfs(s[i][1]);   // 再左
            if (s[i][2] != '*') dfs(s[i][2]);   // 后右
        }
    }
}

int main() {
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> s[i];
        vis[s[i][1]] = true;            // 左儿子被当过孩子
        vis[s[i][2]] = true;            // 右儿子被当过孩子
    }
    for (int i = 0; i < n; i++)
        if (!vis[s[i][0]]) { dfs(s[i][0]); break; }  // 没被当过孩子的就是根
    return 0;
}
```
