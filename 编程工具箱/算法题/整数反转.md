# 题干
#边界判断 #LeetCode
给你一个 32 位的有符号整数 `x` ，返回将 `x` 中的数字部分反转后的结果。

如果反转后整数超过 32 位的有符号整数的范围 `[−231,  231 − 1]` ，就返回 0。

**假设环境不允许存储 64 位整数（有符号或无符号）。**

**示例 1：**

**输入：**x = 123
**输出：**321

**示例 2：**

**输入：**x = -123
**输出：**-321

**示例 3：**

**输入：**x = 120
**输出：**21

**示例 4：**

**输入：**x = 0
**输出：**0

**提示：**

- `-231 <= x <= 231 - 1`
# 我的题解
```java
class Solution {
    public int reverse(int x) {
        int result=0;
        if(x>=0){
            while(x!=0){
                int cuur=x%10;
                int temp=result*10+cuur;
                if((temp-cuur)/10!=result){
                    result=0;
                    break;
                }
                result=temp;
                x/=10;
            }
        }else{
            x=-x;
            while(x!=0){
                int cuur=x%10;
                int temp=result*10+cuur;
                if((temp-cuur)/10!=result){
                    result=0;
                    break;
                }
                result=temp;
                x/=10;
            }
            result=-result;
        }
        return result;
    }
}
```
## 主要难点
int x反转后是否超出int类型边界的判断
## 解决思路
可以每次操作后的数字用临时变量存储，对该变量反向运算，

若与操作前的结果不等，则发生溢出，直接返回0
```JAVA
	while(x!=0){
		int cuur=x%10;
		int temp=result*10+cuur;
		//判断是否溢出的关键
		if((temp-cuur)/10!=result){
			result=0;
			break;
		}
		result=temp;
		x/=10;
	}
```
# 其他方法
int类型的数字翻转也不会超过long的范围，所以可以利用long类型和int类型转换后

判断是否相等来验证是否超出int范围
```java
	public int reverse(int x) {
	    long result = 0;
	    while(x != 0){
	        int cuur = x%10;
	        result = result *10 + cuur;
	        x = x/10;
	    }
	    //如果不超出范围，强转类型后数值不变化
	    int res = (int)result;
	    return res == result? res: 0;
	}
```
