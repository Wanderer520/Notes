# 题干
**题目**：统计二叉树的结点总数与叶子结点数（递归），扩展：再统计度为 1、度为 2 的结点数（王道课后题）
> 要求：递归实现 ｜ 对应手写清单 A1 遍历 ｜ 绿区

# 我的题解

## 方法一：递归统计结点总数与叶子结点数
结点总数 = 左子树结点数 + 右子树结点数 + 1（根自己）；叶子 = 左右孩子都为 NULL。空树是递归出口，贡献 0。

时间复杂度 O(n)（每个结点访问一次），空间复杂度 O(h)（h 为树高，递归栈深）。

```c
/* ---------- 结构定义（王道标准命名） ---------- */
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

/* ---------- 结点总数 ---------- */
int BiTreeSize(BiTree T) {
    if (T == NULL)
        return 0;                              // 空子树贡献 0
    return BiTreeSize(T->lchild) + BiTreeSize(T->rchild) + 1;  // 左 + 右 + 根自己
}

/* ---------- 叶子结点数 ---------- */
int LeafSize(BiTree T) {
    if (T == NULL)
        return 0;                              // 空子树贡献 0
    if (T->lchild == NULL && T->rchild == NULL)
        return 1;                              // 左右都没有孩子 → 叶子
    return LeafSize(T->lchild) + LeafSize(T->rchild);
}
```

## 方法二：公式法统计度为 1、度为 2 的结点数
二叉树性质推导：设 n0、n1、n2 分别是度为 0、1、2 的结点数。
- 总结点数：n0 + n1 + n2 = size
- 边数 = 结点数 - 1，且每条边对应一个孩子，所以 n1 + 2·n2 = size - 1
- 两式相减得：**n0 = n2 + 1**（叶子数 = 度 2 结点数 + 1）

反解：n2 = n0 - 1，n1 = size - 2·n0 + 1。所以知道 size 和叶子数就能推出 n1、n2，不用额外遍历。

```c
/* ---------- 度为 1 的结点数：n1 = size - 2*n0 + 1 ---------- */
int degree1(BiTree T) {
    if (T == NULL)                            // 空树没有结点，公式失效，必须特判
        return 0;
    return BiTreeSize(T) - 2 * LeafSize(T) + 1;
}

/* ---------- 度为 2 的结点数：n2 = n0 - 1 ---------- */
int degree2(BiTree T) {
    if (T == NULL)
        return 0;
    return LeafSize(T) - 1;
}
```

复杂度：每个函数 O(n) 时间（内部再走递归）、O(h) 空间。degree1 / degree2 分开调用会重复遍历，更省的做法是**一趟递归同时数出 n0、n1、n2**（三个计数用指针参数带回）。

# 手写易错点

- **BiTreeSize 的递归结构**：`return 左 + 右 + 1` 三者缺一不可。写成 `else return 1;` 再接递归是逻辑错误——`return` 已经把值返回了，后面的递归永远执行不到，结果恒为 1；`retrun` 这种拼写错误编译器直接报错。
- **形参类型**：王道命名下 `BiTree` 本身就是 `BiTNode*`，直接传 `BiTree T`；写成 `BiTree* T` 是二级指针，`T->lchild` 编译不过（需要改父指针时才用二级指针，见 [[二叉搜索树 BST]]）。
- **公式法的空树特判**：n0 = n2 + 1 只在非空二叉树成立，空树直接套公式会算出 degree1 = 1、degree2 = -1 的荒谬结果，必须 `if (T == NULL) return 0;`。
- **叶子判断**：叶子 = 左右孩子都为 NULL。只判断一边（如 `!T->lchild`）会把单分支结点误判成叶子。
- **全角符号**：`return 0；` 的分号必须用半角 `;`，全角分号不是合法 C 语法。
