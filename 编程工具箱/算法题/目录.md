# 算法题目录
> 全部 LeetCode / 洛谷题解，按知识点归类。复习时按"招式"找题，回到 [[编程工具箱/目录|编程工具箱]]。

## 单调栈
- [[每日温度]]：下一个更大元素，答案存距离
- [[商品折扣后的最终价格]]：变体——找右侧第一个 ≤ 当前价格的元素

## 计数排序
- [[有多少小于当前数字的数字]]：计数 + 前缀和，O(n) 统计比当前小的数

## 滑动窗口 / 双指针
- [[无重复字符的最长子串]]：双指针维护无重复窗口，O(n)；"冲突时平移不重扫"的 KMP 同款内核

## 数组
- [[到目标字符串的最短距离]]：环形数组，双向搜索取最小步数

## 矩阵
- [[旋转图像]]：原地旋转 90°，三种方法对比

## 链表
- [[两数相加]]：链表模拟加法，注意进位

## 树
- [[求深度或高度]]：王道大题，递归（后序）+ 层序（last 指针）求二叉树高度
- [[结点统计]]：王道大题，递归数结点/叶子 + 二叉树性质公式推度 1、度 2

## 栈 / 队列
- [[有效的括号]]：栈匹配括号，右括号必须与栈顶同型左括号配对
- [[表达式括号匹配]]：P1739 洛谷，只含圆括号的最简栈匹配
- [[约瑟夫问题]]：P1996 洛谷，队列循环模拟出圈顺序
- [[用栈实现队列]]：双栈（输入栈 + 输出栈）实现 FIFO
- [[最小栈]]：双栈（数据栈 + 辅助最小值栈），O(1) 取最小
- [[函数的独占时间]]：用栈模拟调用栈，计算独占时间

## 数学 / 边界
- [[整数反转]]：int 溢出检测的两种思路
