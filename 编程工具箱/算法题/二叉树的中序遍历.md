# 题干
给定一个二叉树的根节点 `root`，返回它的**中序**遍历。

**示例 1：**

**输入：**root = [1,null,2,3]

**输出：**[1,3,2]

**示例 2：**

**输入：**root = []

**输出：**[]

**示例 3：**

**输入：**root = [1]

**输出：**[1]

**提示：**

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**进阶：**递归算法很简单，你可以通过迭代算法完成吗？

# 我的题解
思路：中序遍历的顺序是**左子树 → 根 → 右子树**。递归版直接按这个顺序写：先递归左子树、把根的值加入结果、再递归右子树。"访问根"这一句放在两次递归调用的**中间**就是中序——把它移到最前面是前序、移到最后是后序，同一段递归骨架，移动一行代码就换了遍历方式。

时间复杂度 O(n)（每个节点访问一次），空间复杂度 O(n)（递归栈深 = 树高，最坏链状树 O(n)）。

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> list = new ArrayList<Integer>();
        InOrder(root, list);
        return list;
    }

    public static void InOrder(TreeNode root, List<Integer> list) {
        if (root != null) {
            InOrder(root.left, list);   // ① 先左子树
            list.add(root.val);         // ② 再根（这句在中间 = 中序）
            InOrder(root.right, list);  // ③ 后右子树
        }
    }
}
```

> 已用 Python 等价验证：递归版与官方迭代版在 3000 棵随机树上结果完全一致；BST 上中序输出严格升序（"左根右"语义正确）。

# 官方题解
思路：递归本质是系统栈，**迭代版就用显式栈模拟**——从根出发"一路向左"全部入栈（相当于不断压入左子树递归）；栈空不了时，弹出栈顶（最左节点）访问，然后转向它的右子树继续同样的过程。循环条件 `root != null || !stack.isEmpty()` 保证"左走到底 + 回溯 + 转右"完整走完。

- 一路向左入栈 → 弹出的顺序天然就是"最左的先访问"；
- 访问完一个节点立即转向右子树 → 右子树的中序会在它之后输出。

时间复杂度 O(n)，空间复杂度 O(n)（栈）。

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<Integer>();
        Deque<TreeNode> stk = new LinkedList<TreeNode>();
        while (root != null || !stk.isEmpty()) {
            while (root != null) {   // 一路向左，全部入栈
                stk.push(root);
                root = root.left;
            }
            root = stk.pop();        // 弹出最左节点
            res.add(root.val);       // 访问
            root = root.right;       // 转向右子树
        }
        return res;
    }
}
```
