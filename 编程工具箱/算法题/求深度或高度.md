# 题干
**题目**：设计算法求二叉树的深度（高度），二叉树采用二叉链表存储（王道课后题）
> 要求：递归版 + 层序非递归版各写一遍 ｜ 对应手写清单 A1 遍历 ｜ 绿区

# 我的题解
## 方法一：递归（后序思想的典型应用）
空树高度为 0；否则高度 = max(左子树高度, 右子树高度) + 1。先递归算左右子树、再算自己——本质是**后序遍历**。

时间复杂度 O(n)（每个结点访问一次），空间复杂度 O(h)（h 为树高，递归栈深）。

```c
/* ---------- 结构定义（王道标准命名） ---------- */
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

/* ---------- 递归求深度 ---------- */
int depthRec(BiTree T) {
    if (T == NULL)                 // 空树高度为 0
        return 0;
    int ld = depthRec(T->lchild);  // 左子树高度
    int rd = depthRec(T->rchild);  // 右子树高度
    return (ld > rd ? ld : rd) + 1; // 高的那边 + 根这一层
}
```

## 方法二：层序非递归（last 指针法）
层序遍历时用 `last` 记录**当前层的最后一个结点**：出队到 `front == last` 说明一层走完，层数 +1，同时把 `last` 更新为下一层的末尾（当前 `rear`）。

时间复杂度 O(n)，空间复杂度 O(n)（队列最多存满一层）。

```c
/* ---------- 层序非递归求深度 ---------- */
int depthIter(BiTree T) {
    if (T == NULL)             // 空树深度为 0（漏掉会空指针崩）
        return 0;
    BiTree Q[MaxSize];         // 数组队列（容量足够大即可）
    int front = -1, rear = -1; // 先 ++ 再存取
    int last = 0, level = 0;   // 关键：last 初始指向根（下标 0）
    Q[++rear] = T;             // 根入队
    BiTree p;
    while (front < rear) {     // 队不空
        p = Q[++front];        // 出队
        if (p->lchild) Q[++rear] = p->lchild;
        if (p->rchild) Q[++rear] = p->rchild;
        if (front == last) {   // 出队出到当前层最后一个
            level++;           // 深度 +1
            last = rear;       // last 跳到下一层最后一个
        }
    }
    return level;
}
```

> 王道标准答案就是这两种写法（递归 + 层序），这题没有第三种官方套路。

# 手写易错点

- **形参类型**：`BiTree` 本身就是 `BiTNode*`，这里不需要改父指针，直接传 `BiTree T` 即可；写成 `BiTree* T` 会变成二级指针，`T->lchild` 就错了（插入/删除才需要二级指针，见 [[二叉搜索树 BST]]）。
- **空树高度**：王道约定空树高度为 0；个别教材/题目约定为 -1，先看题设。层序版**必须加空树特判**，否则 `p = Q[++front]` 后解引用空指针崩。
- **层序的 last 指针**：`last` 初始是 0（根的数组下标），出队到 `front == last` 才层数 +1，并 `last = rear`。漏掉 `last = rear` 会死循环/只算 1 层。
- **深度 vs 高度**：结点的**深度**是从根往下数的层数，树的**高度** = 最大深度；有些题从 0 计数、有些从 1 计数，答案差 1，以题设为准。
- 递归求高度是**后序**（先左右后根）思想的典型应用——遍历三顺序里后序最适合"先算子树再汇总"。
